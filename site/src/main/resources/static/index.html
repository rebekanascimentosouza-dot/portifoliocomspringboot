Meu nome é Rebeka e faço o Ensino Médio Integrado com Desenvolvimento de Sistemas.

Conheça um pouco sobre o que aprendi em Back-End!

O que é Back-End?

Back-End é a parte de um site ou sistema responsável por fazer tudo funcionar por trás das telas. É onde acontecem os processos, o armazenamento de informações e a comunicação com o banco de dados.

O que aprendemos no curso?

1. Lógica de Programação

Aprendemos a desenvolver o raciocínio lógico, criar algoritmos, utilizar variáveis, condições e estruturas de repetição para resolver problemas.

2. Linguagens de Programação

Conhecemos conceitos de programação e aprendemos a escrever códigos para desenvolver funcionalidades de sistemas.

3. Banco de Dados

Aprendemos sobre o armazenamento e a organização de informações, além de criar tabelas e entender como os dados são utilizados em um sistema.

4. SQL

Conhecemos comandos SQL para criar, consultar, inserir, atualizar e excluir informações em bancos de dados.

5. Servidores e Sistemas

Aprendemos que o Back-End trabalha com servidores, recebendo solicitações dos usuários e enviando respostas para o Front-End.

O que eu aprendi?

Durante as aulas, desenvolvi conhecimentos importantes sobre programação, lógica e funcionamento dos sistemas. Também aprendi que o Back-End é essencial para que sites e aplicativos funcionem corretamente.

Conclusão

Estudar Back-End está sendo uma experiência importante para minha formação em Desenvolvimento de Sistemas. Cada conteúdo aprendido contribui para meu crescimento e para minha preparação para o futuro profissional na área de tecnologia.
